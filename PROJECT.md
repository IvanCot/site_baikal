# Контекст проекта

SSH-адрес GitHub: `git@github.com:IvanCot/site_baikal.git`.

Система внутреннего управления гостевым домом «У батюшки». Весь интерфейс,
документация и сообщения пользователю — на русском языке.

Основной стек: Python 3.12, Django 5.2, PostgreSQL, серверные шаблоны,
CSS и небольшой JavaScript, Docker Compose, Nginx. Не использовать публичную
раздачу загруженных документов. Завершённые бронирования сохраняются навсегда.

Встроенная модель User расширена полем роли. Администратор управляет данными,
сотрудник видит оперативные сведения, заселяет, выселяет и завершает уборку.
Финансы, справочник гостей, документы и настройки доступны администратору.

Связи: Room → Booking; Guest → Booking как основной гость;
Booking ↔ Guest через BookingGuest для сопровождающих; Booking → Payment;
Guest / Booking → Document; User → AuditLog и автор платежа.

Состояния брони: reserved → occupied → completed; reserved → cancelled.
Редактирование дат и состава доступно до завершения. Служебное состояние
номера хранится отдельно: ready, cleaning, unavailable. При выселении — cleaning.
Фактическое проживание имеет приоритет над плановыми датами на главной странице.

Проверка пересечений использует полуоткрытые интервалы [заезд, выезд),
транзакцию с блокировкой строки номера и ограничение EXCLUDE в PostgreSQL.
Смежные интервалы допустимы. Отменённые и завершённые брони не блокируют даты.

Основные маршруты: /, /calendar/, /bookings/, /guests/, /rooms/, /payments/,
/history/, /settings/, /audit/, /documents/<id>/.
Операции изменения состояния принимают только POST и защищены CSRF.
